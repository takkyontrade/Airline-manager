# 航空会社運営ゲーム（仮）

1960年の日本で航空会社を立ち上げ、実際の航空史に沿って経営していく、ブラウザで遊ぶ1人用のターン制経営シミュレーションです。

仕様書: https://claude.ai/artifact/Gqra1eGitTu53mLP3ErsPx

## 遊び方（手元で動かす）

Node.js 20 以上が必要です。

```
npm install
npm run dev
```

表示されたURL（例: http://localhost:5173）をブラウザで開きます。

## 今できること（第1段階）

- 会社名と拠点空港を決めて1960年1月からスタート（資本金5億円）
- 日本地図で空港を2つクリックして路線を開設
- 機材市場で新造機・中古機を購入またはリース
- 路線ごとに運賃と週の便数を設定し、機体を割り当て
- 「1か月進める」で需要・旅客数・収支を計算（燃料費・整備費・人件費・空港使用料・リース料など）
- 資金がマイナスのまま3か月続くと倒産
- ブラウザへの自動保存と、ファイルへの書き出し・読み込み

## 第2段階で追加したこと

- 新造機の発注（機種ごとの納期、手付金20%・残金は納入時）
- リース3種類：オペレーティング（3〜12年）、ファイナンス（10年で自社のものに）、ウェット（乗員・整備込みの短期）
- 毎月入れ替わる中古機市場（機齢・状態・飛行時間つき）
- 銀行借入（時代ごとの金利、担保と利益で借入枠が決まる）と一括返済
- 機種ごとのパイロット資格：経験者採用（毎月の上限あり）、新人訓練・移行訓練（4か月）。足りないと飛べない
- 整備の方針（節約・標準・手厚い）、機体の状態と経年劣化（燃費・快適さに影響）
- 飛行5,000時間ごとの重整備（Cチェック1か月、3回に1回はDチェック2か月）、期限切れは飛行停止

## 第3段階で追加したこと

- 機体ごとの1日のダイヤ（曜日指定つき）。路線ごとに「週の目標便数・使う機種・ダイヤの方針」を決めると自動で組む
- 方針：詰めて組む／一日に均等／朝夕を厚く／ハブで乗り継ぎ（運航計画部門の規模で使えるものが増える）
- ダイヤ画面で機体ごとのタイムラインを確認し、手動で便の追加・時刻変更・削除。手で直した機体は「固定」
- 折り返しの余裕時間の設定。遅延はその日の後の便に連鎖し、空港の運用時間を過ぎると欠航
- 定時率が評判と旅客の選択に影響。混雑空港・冬の雪・夏の台風で遅れやすい
- 空港の運用時間（門限）と、羽田・伊丹の発着枠（毎年4月に追加配分）
- 乗員基地：機体の拠点が基地でないとホテル代がかかる
- 出発時刻の人気（朝夕は高く、昼や深夜は低い）

## 開発

```
npm test          # ゲーム計算のテスト
npm run balance   # バランス確認用の試算
npm run build     # 公開用ビルド（dist/）
```

- `src/data/` 空港・機種・経済指標のデータ（数値は概算）
- `src/engine/` ゲームの計算（画面から独立）
- `src/ui/` 画面
