# 航空会社運営ゲーム（仮）

1960年の日本で航空会社を立ち上げ、実際の航空史に沿って経営していく、ブラウザで遊ぶ1人用のターン制経営シミュレーションです。

仕様書: https://claude.ai/artifact/Gqra1eGitTu53mLP3ErsPx

## 遊び方（手元で動かす）

Node.js 20 以上が必要です。

```
npm install
npm run dev
```

表示されたURL（例: http://localhost:5173）をブラウザで開きます。

## 今できること（第1段階）

- 会社名と拠点空港を決めて1960年1月からスタート（資本金5億円）
- 日本地図で空港を2つクリックして路線を開設
- 機材市場で新造機・中古機を購入またはリース
- 路線ごとに運賃と週の便数を設定し、機体を割り当て
- 「1か月進める」で需要・旅客数・収支を計算（燃料費・整備費・人件費・空港使用料・リース料など）
- 資金がマイナスのまま3か月続くと倒産
- ブラウザへの自動保存と、ファイルへの書き出し・読み込み

## 開発

```
npm test          # ゲーム計算のテスト
npm run balance   # バランス確認用の試算
npm run build     # 公開用ビルド（dist/）
```

- `src/data/` 空港・機種・経済指標のデータ（数値は概算）
- `src/engine/` ゲームの計算（画面から独立）
- `src/ui/` 画面
